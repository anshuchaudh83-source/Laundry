# Smart Laundry Management System

## Project Overview
The Smart Laundry Management System is a Java-based application developed using Java 8 and Java Swing. It simulates a laundry facility where multiple customers use shared resources such as washing machines, dryers, and payment kiosks.

## Features
- Multiple customer threads running simultaneously.
- Washing machine and dryer resource management.
- Payment kiosk management.
- Thread synchronization and resource sharing.
- Automatic retry when washing or payment fails.
- Real-time simulation monitoring through a graphical interface.
- Customer activity and simulation logging.

## Technologies Used
- Java 8
- Java Swing
- Multithreading
- Concurrent Programming
- Thread Synchronization

## Project Purpose
This project demonstrates the practical use of concurrent programming concepts, including thread management, synchronization, and shared resource handling.
